Cliente Telnet nativo para Android.
Interface moderna para o sistema WMS infoDesign.

Versão 1.0.0
Plataforma Android 5.0+
Tamanho ~3 MB
Protocolo Telnet TCP
Baixar APK

⚠ Antes de instalar, ative Fontes desconhecidas nas configurações do Android.
Configurações → Segurança → Permitir fontes desconhecidas (ou Instalar apps desconhecidos).

Como instalar

1
Baixe o APK
Toque no botão acima no próprio coletor ou transfira o arquivo via USB.
2
Permita fontes desconhecidas
Configurações → Segurança → Ative "Instalar apps desconhecidos".
3
Instale o APK
Abra o arquivo baixado e confirme a instalação.
4
Configure o perfil
Abra o app → menu ☰ → "+" → informe o IP e porta do servidor WMS.

Funcionalidades

📱
Interface nativa
Telas WMS convertidas em layout Android moderno.
📷
Leitor de barras
Compatível com leitores HID e câmera.
🔁
Reconexão automática
Reconecta sozinho em caso de queda de conexão.
💾
Perfis salvos
Salva múltiplos servidores e encodings.
